# 🌱 Professional Garden Plant Irrigation System

This project is a professional garden irrigation system designed to automate the watering of plants using advanced IoT technologies. The system is powered by an ESP32 microcontroller and integrates several key components to monitor and maintain optimal plant health.

---

## 📋 Features

- **ESP32 Microcontroller**  
  Acts as the central hub for data processing, control, and WiFi connectivity.

- **DHT11 Sensor**  
  Measures temperature and humidity to monitor environmental conditions.

- **Soil Moisture Sensor**  
  Detects the soil moisture level to ensure plants receive the right amount of water.

- **OLED Display**  
  Displays real-time data, including temperature, humidity, and soil moisture levels.

- **WiFi Control**  
  Enables remote monitoring and control of the system through a web interface or mobile app.

- **Electrovalve Control**  
  Automatically operates the irrigation system based on sensor data, ensuring water is delivered efficiently when needed.

---

## 🚀 How It Works

1. **Data Monitoring**  
   The DHT11 sensor provides temperature and humidity readings, while the soil moisture sensor monitors the moisture level in the soil.

2. **Real-Time Display**  
   All data is displayed on an OLED screen for easy local monitoring.

3. **Remote Control**  
   The ESP32 serves a web interface, allowing users to view data and manually control the irrigation system over WiFi.

4. **Automatic Irrigation**  
   When soil moisture drops below a defined threshold, the system automatically activates the electrovalve to water the plants.

5. **Energy Efficiency**  
   The system uses low-power components to ensure it can operate for extended periods with minimal energy consumption.
